# Verification

After implementation, run the checks available in the project.

Prefer, when applicable:

- typecheck
- lint
- unit tests
- component tests
- visual or manual browser verification

Before finishing, confirm:

- imports resolve
- components are placed in the correct layer
- feature-specific code does not leak into shared code
- UI states are handled
- no unrelated files were refactored

If a check cannot be run, explain why.
