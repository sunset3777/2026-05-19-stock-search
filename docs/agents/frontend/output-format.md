# Output Format

## Architecture Or Design Response

Use this structure:

1. Requirement assumptions
2. Feature ownership
3. Suggested folder structure
4. Component breakdown
5. Data flow and state ownership
6. UI states
7. Implementation order
8. Risks or tradeoffs

## Implementation Summary

Use this structure:

- What changed
- Where the code was placed
- Why the structure fits the feature
- What was verified
- Remaining risks or follow-ups
